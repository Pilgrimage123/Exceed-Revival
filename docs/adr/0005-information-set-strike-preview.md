# Information Set Strike Preview

We run `SimulateStrikePreview.run(infoSet, candidateCard, opts)` as a pure, phase-ordered simulation over the active player's `Information Set` (`Engine.prototype.getInformationSet(playerId)`) sharing extracted pure stat, movement (`Engine.simulateMovementPath`), and range rules with `engine.js`, rather than deep-cloning `Engine` and running `*resolveStrikeSteps` on a redacted clone.

- **Fog-of-War Guarantee**: Structurally never touches opponent hidden hand, deck order, or face-down Strike cards; `getInformationSet` exposes only public board/zone state plus the actor's own hand and own-turn flags (`canceledThisTurn`, `actionStrikeThisTurn`).
- **Full Phase Parity**: Simulates live stats (post-set hand size, EX, Critical, boosts, innates) → effective range (numeric `normalsRangeBonus`/`attackRangeBonus`, boost/dynamic/initiating bonuses) → `Before:` movement (with `selfMoveCap` and `opponentCannotMove`) → range/origin/immunity hit validation (including Eddie origin, cross-up range inclusion, `rangeImmuneRanges`, `noHitWithoutContinuousBoost`) → `Hit:` hooks (opponent push/pull, wall-bounce POW bonuses, heals, Advantage, optional Force/Gauge branches) → damage, guard-break, and life loss (`oppLifeBefore → oppLifeAfter`) → `After:` movement (running even on whiff) → Cleanup self-damage (`selfLifeDelta`).
- **Synchronized Multi-Surface UI**: `StrikePreviewController` updates the Arena Telegraph (hitbox, target hit/miss highlight, impact tags, arrowed Before/Push/After splines, Eddie origin), HUD Life Bars (projected damage bar + HP deltas), Clash Summary Banner, and Universal Inspector in-place without repainting `#app`, while `PreviewMemo` drives accurate `hits after move ✓` / `in range ✓` / `out of range ✗` hand chips.

See [`docs/strike-preview.md`](../strike-preview.md) for the full specification and output schema.
