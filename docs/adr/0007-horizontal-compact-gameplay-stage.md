# Horizontal Compact Gameplay Stage

We render the active gameplay screen as a viewport-locked (`100dvh` at `>= 1024px`) horizontal two-column layout—a Main Stage (~72%) stacking slim fixed-height Fighter HUDs, a flexible 9-Space Arena with an inline Stage Prompt Bar, a single-row Action Bar, and one unified compact Hand Dock alongside a collapsible Right Rail (~28%) housing utility controls, a pinned universal Inspector (for hovered/selected cards, Innate/Continuous Boost pills, and revealed Strikes), and tabbed `Log` / `Normals` / `Coach` panels—rather than a vertically scrolling single-column stack with full-text hand cards, floating tooltips, and duplicate sub-mode hand rows. This keeps the 9-Space Arena, all 7 hand cards, and active controls simultaneously visible with zero vertical scrolling, zero layout shift on hover, and zero obstruction of Arena Spaces.
